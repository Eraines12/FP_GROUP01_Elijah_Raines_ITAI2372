AI Spacecraft Anomaly Detection System
Name: Elijah Raines
Course: ITAI 2372
Track: Conceptual Design

Project Description
This project is about designing an AI system that can detect problems in spacecraft systems before they become serious. The system would analyze sensor data and identify unusual patterns that could indicate a failure. This project focuses on designing an AI system that can monitor spacecraft systems in real time and automatically detect anomalies before they become critical failures. The system would use machine learning models trained on sensor data to identify unusual patterns in things like temperature, pressure, and power usage. If an issue is detected, the AI can classify the problem and suggest possible fixes, reducing the need for constant human monitoring.
